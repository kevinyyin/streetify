# Streetify

The app's name is Streetify; the code, Xcode target and scheme keep the name GapCheck.

iOS app for blind pedestrians at unsignalized crossings. The user holds the iPhone sideways and level, by the end without the cameras, cameras toward the street and screen facing left (2026-10-10); the front and back cameras look down the road both ways. Each direction reports Clear, Approaching (with seconds to arrival) or Unknown (with a reason), through haptics, a tone and short speech. Everything runs on-device. Scope: ~25 mph streets, 1 to 2 lanes, user standing at the curb.

## Safety invariants

1. Never say, show or speak "safe", "go", "cross now" or similar. Report only what is seen.
2. Every failure ends in Unknown, never Clear. Initial state is Unknown.
3. Bias toward false alarms. Ask before any change that could reduce detections.
4. Each invariant has a unit test.

## Project setup

- The Xcode project is generated by XcodeGen from `project.yml`. `GapCheck.xcodeproj` is gitignored; never edit it by hand. New files go on disk, then `xcodegen generate`.
- `Local.xcconfig` (gitignored) holds each person's `DEVELOPMENT_TEAM` and a unique `PRODUCT_BUNDLE_IDENTIFIER`, so regenerating never wipes signing.
- Approved dev tools: Homebrew, XcodeGen, Python with ultralytics (model export only).

## Commands

```
xcodegen generate
xcodebuild -scheme GapCheck -destination 'platform=iOS Simulator,name=iPhone 17' -collect-test-diagnostics never test
xcodebuild -scheme GapCheck -destination 'platform=iOS Simulator,name=iPhone 17' -collect-test-diagnostics never test -only-testing:GapCheckTests/<Class>
.venv/bin/yolo export model=yolo11n.pt format=coreml nms=True imgsz=640   # then move yolo11n.mlpackage to GapCheck/Pipeline/
.venv/bin/python tools/export_car_orientation.py   # front/rear model; needs tools/convnext-multi-weak.pth (see the script) and timm
```

Model export venv: Python 3.12 with torch 2.7, coremltools 9.0, numpy<2.3 (coremltools fails on Python 3.14 with torch 2.14). Rebuild it with `"$(brew --prefix python@3.12)/bin/python3.12" -m venv .venv && .venv/bin/pip install "torch==2.7.*" "torchvision==0.22.*" ultralytics "coremltools==9.0" "numpy<2.3"`.

## How to work

- Keep going when a step doesn't need me; put status notes in the same message as your next action.
- Stop and ask only when blocked, or before: deleting anything in Footage/, force-pushing, changing signing, touching anything outside the repo, or anything under invariant 3.
- "Pair mode": one-line plan before, short recap after, until I say "solo mode".
- Build only what TASKS.md lists; ask before adding items. Keep TASKS.md ticked and current.
- Apple frameworks plus the CoreML model only. Only FrameSource is a protocol.
- All timing uses frame timestamps, except the live stale-frame watchdog.
- Done = builds, tests pass, TASKS.md updated. Label anything only checkable on a real iPhone "not verified on device".
- Reviews: list only merge-blocking problems, each with file, line, why, and how to show it fails.
- End every run with: **Blocked on me**, **Changed**, **Found**.

## Conventions

- Swift and SwiftUI. Units in names (`heightPixels`, `clearHoldSeconds`).
- Every tunable constant in `Config.swift` with a one-line comment.
- Every UI element has a VoiceOver label.
- Debug overlay: plain and legible. No cream backgrounds, gradients, frosted cards, pill buttons, emoji or monospace labels.
