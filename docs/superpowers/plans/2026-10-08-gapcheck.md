# GapCheck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iOS app that watches both directions of a street with the front and back cameras and reports Clear / Approaching (seconds) / Unknown (reason) for each direction through haptics, tone and speech, all on-device.

**Architecture:** One pipeline per camera on its own serial queue: FrameSource → Detect (YOLO11n through Vision, whole frame plus center tile) → Track (IoU tracker, time to arrival from box-height growth) → Decide (ordered rules, Unknown by default). A pure `announce` function turns state changes into feedback events, and thin adapters play them.

**Tech Stack:** Swift, SwiftUI, AVFoundation (AVCaptureMultiCamSession, AVAssetReader), Vision + CoreML (yolo11n.mlpackage), CoreMotion, CoreHaptics, AVAudioEngine, AVSpeechSynthesizer, XCTest, XcodeGen.

**Spec:** `CLAUDE.md`, `GapCheck/Pipeline/CLAUDE.md`, `GapCheck/Feedback/CLAUDE.md`, plus the **Decisions** below, which Task 1 writes into those files. Repo root: `/Users/kevinyin/streetify/streetify-claude-files`.

## Decisions (approved in brainstorming; Task 1 writes them into the spec files)

**Capture**
- Gravity picks the hold on every frame (portrait, portraitUpsideDown, landscapeLeft, landscapeRight). Vision gets the matching EXIF orientation for each camera, and tracks reset when the orientation changes.
- Level means pitch ≤ `levelPitchToleranceDegrees = 8` and roll ≤ `levelRollToleranceDegrees = 10`. A phone held between two holds has a large roll, so it reads not level.
- `isIdleTimerDisabled = true` while the app runs. The UI is locked to portrait.

**Detect**
- The whole-frame request uses `.scaleFit`. The default `.centerCrop` drops about 44% of the frame.
- Tile boxes are mapped back to full-frame coordinates.
- Overlapping boxes (IoU ≥ `mergeIoU = 0.5`) keep the tile box, unless the tile box touches the tile edge (within `tileEdgeMarginFraction = 0.01`).
- Detections need confidence ≥ `minDetectionConfidence = 0.25`.

**Track**
- Match on IoU ≥ `matchIoU = 0.3`, otherwise the nearest center within `matchRadiusBoxHeights = 1.0`.
- A track is dropped after `trackLostSeconds = 0.5` without a match.
- Time to arrival = mean height / slope − (now − mean time). This is unbiased for accelerating growth; using the last height would overestimate time to arrival by about 18% at 8.5 s.

**Decide**
- Rule 4: a track counts as approaching if it is too new to measure, or if `lowSeconds < approachWindowSeconds`. `lowSeconds` is computed from slope + `tauConfidenceSigmas = 2` × the slope's standard error.
  - The spoken number comes from the point estimate. If there's no usable point estimate, it says "far".
  - Accepted cost: distant parked cars read "Approaching, far".
- Rule 5: a track that isn't approaching counts as stationary. `blockedFraction = 0.3` of the tile area.
- Rule 3 start values (calibrate on Footage): `minMeanLuma = 0.08`, `maxMeanLuma = 0.95`, `minLaplacianVariance = 10`.
- Rule 1:
  - On replay, a gap between frame timestamps longer than 300 ms fires `stale`.
  - A frame whose detection throws never updates Decide, so failures end in `stale`.

**Feedback**
- **Banned-words test deferred** by the user (2026-10-08). Invariant 1 has no unit test for now, but strings are still written without those words.
- A change means a change of kind, a change of Unknown reason, or Approaching switching between far and timed. The countdown is carried by the tone's pitch only.
- Output is coalesced for `announceCoalesceSeconds = 0.2`, and identical sentences are spoken once.
- The haptic follows the most urgent new state: Approaching > Unknown > Clear. The ready haptic plays when the phone becomes level.
- **Tone:** one sine oscillator.
  - Aiming band: `aimMinHz = 200` … `aimMaxHz = 500`, rising as the phone gets closer to level.
  - Approaching band: `approachMinHz = 600` … `approachMaxHz = 1200`, rising as the car nears, panned to the side of the nearest car.
- **Speech:** a high-priority VoiceOver announcement when VoiceOver is running, otherwise `AVSpeechSynthesizer` with `stopSpeaking(.immediate)`. The audio session is `.playback` + `.mixWithOthers`.

**UI and tests**
- **One screen:** it doubles as the debug overlay. It shows processed frames with boxes, a state line per side, and "Replay left…" / "Replay right…" buttons that open `.fileImporter`.
- **Tests run on the iOS simulator.**
- **Footage report:** it needs a `<clip>.passes.txt` file beside each clip, with one pass time in seconds per line.

## Global Constraints

- Never say, show or speak "safe", "go", "cross now" or similar. Report only what is seen.
- Every failure ends in Unknown, never Clear. Initial state is Unknown.
- Bias toward false alarms. Ask before any change that could reduce detections, or that changes a threshold, window, tile position, model or rule order.
- Apple frameworks plus the CoreML model only. Only FrameSource is a protocol.
- All timing uses frame timestamps, except the live stale-frame watchdog.
- Units in names. Every tunable constant lives in `Config.swift` with a one-line comment.
- Every UI element has a VoiceOver label.
- Debug overlay: no cream backgrounds, gradients, frosted cards, pill buttons, emoji or monospace labels.
- XcodeGen only: never edit `GapCheck.xcodeproj`. New files go on disk, then `xcodegen generate`.
- iOS 17.0 deployment target (iPhone XS/XR and newer).
- Anything only checkable on a phone is labelled "not verified on device".
- Pair mode: a one-line plan before each task and a short recap after. End every run with **Blocked on me**, **Changed**, **Found**.
- `TEST <Class>` means: `xcodebuild -scheme GapCheck -destination 'platform=iOS Simulator,name=$SIM' test -only-testing:GapCheckTests/<Class>`. `$SIM` is set in Task 1.

1. Detection throws on a frame → Decide is never updated → the watchdog or a frame gap goes `stale`. Never Clear. (Task 7 `testNoFramesAfterClearGoesStale`; Task 8 skips Decide when detection throws.)
2. The phone rotates between portrait and landscape mid-track → heights from the old orientation must not feed the fit. (Task 6 `testOrientationChangeResetsTracks`)

### Task 6: Tracker and time to arrival

**Files:** Create `Pipeline/Track.swift`. Modify `Config.swift`, `TestHelpers.swift`. Test: `TrackTests.swift`.

**Produces:**
```swift
struct ArrivalEstimate: Equatable { let isTooNew: Bool; let pointSeconds: Double?; let lowSeconds: Double? } // nil = not closing
struct Track { let id: Int; var box: CGRect; let firstSeenSeconds: Double; var lastSeenSeconds: Double
               var heights: [(t: Double, h: Double)]; func estimate(atSeconds now: Double) -> ArrivalEstimate }
final class Tracker { func update(_ detections: [Detection], atSeconds t: Double, orientation: CGImagePropertyOrientation) -> [Track] }
```
Estimate (the algorithm the tests don't fully determine):
```swift
let s = heights.filter { $0.t >= lastSeenSeconds - Config.historySeconds }
guard lastSeenSeconds - firstSeenSeconds >= Config.historySeconds, s.count >= 3 else { return .init(isTooNew: true, pointSeconds: nil, lowSeconds: nil) }
// tm, hm = means; stt = Σ(t-tm)²; slope = Σ(t-tm)(h-hm)/stt
// se = sqrt(Σ(h - hm - slope*(t-tm))² / (n-2)) / sqrt(stt)
func tau(_ b: Double) -> Double? { b > 0 ? max(0, hm / b - (now - tm)) : nil }
return .init(isTooNew: false, pointSeconds: tau(slope), lowSeconds: tau(slope + Config.tauConfidenceSigmas * se))
```
- Matching is greedy: IoU ≥ 0.3, highest first. Then the nearest center within `matchRadiusBoxHeights × track height`. Otherwise a new id.
- A track is dropped once `t − lastSeen > trackLostSeconds`.
- All tracks reset when `orientation` changes.
- Test helper: `approachingHeights(tauAtEndSeconds:, heightAtEnd:, noisePixels:, seed:)` with h(t) = hEnd·τ/(τ + tEnd − t), 1.5 s at 10 fps, and uniform noise of ±`noisePixels`/1920.

**Produces:**
```swift
enum UnknownReason: Equatable { case stale, notLevel, tooDark, tooBright, covered, viewBlocked }
enum DirectionState: Equatable { case clear, approaching(seconds: Int?), unknown(UnknownReason) }   // nil = "far"
struct Observation { let timestampSeconds: Double; let isLevel: Bool; let quality: ImageQuality; let tile: CGRect }
final class Decider { private(set) var state: DirectionState = .unknown(.stale)
```

- **`update` order:**
  1. On the first frame, set `lastFiredSeconds = t`.
  2. Run `checkStale(t)`, which catches replay gaps.
  3. Set `lastFrameSeconds = t`.
  4. Rules 2→5, first match wins. If one fires, set `state` and `lastFiredSeconds = t`.
  5. Otherwise, if `t − lastFiredSeconds ≥ clearHoldSeconds`, set `.clear`. Otherwise keep the previous state.
- **Rule 3 order:** dark, bright, covered.
- **Rule 4 seconds:** the smallest rounded `pointSeconds` under the window among approaching tracks. If none, nil.
- **Rule 5:** Σ area(non-approaching box ∩ tile) / tile area > 0.3.

**Copy:**
- Clear: "No cars seen left"
- Approaching: "Car right, about 4 seconds", "about 1 second", "Car right, far"
- Unknown: "Left camera stopped", "Hold the phone level", "Left camera too dark", "Left camera too bright", "Left camera covered", "Left view blocked"

**Rules:**
- Combined output lists left then right, dedupes identical sentences and joins with ". ", with no trailing period.
- **Aiming tone:** pan 0. Frequency runs from `aimMinHz` at `aimMaxErrorDegrees = 45` or more off level up to `aimMaxHz` at level.
- **Approaching tone:** pan −1 for left, +1 for right (whichever side has the smaller seconds; far counts as 20). Frequency = `approachMinHz` + (max − min)·(1 − s/20).
- Otherwise the tone is off.
